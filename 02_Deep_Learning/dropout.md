# Dropout в нейронных сетях

## 📌 Основная идея
Dropout — метод регуляризации, предотвращающий переобучение путем случайного "отключения" нейронов во время обучения.

## 🔧 Два типа реализации

### 1. Standard Dropout (Наивный)
**Формула обучения**:
```math
y_{train} = m \odot x
```
где:
- `m ∼ Bernoulli(1-p)` - бинарная маска
- `p` - вероятность дропаута

**Проблема**:  
Снижает матожидание:
```math
𝔼[y_{train}] = (1-p)x
```

**Инференс**:  
Требует ручного масштабирования:
```math
y_{test} = (1-p)x
```

### 2. Inverted Dropout (Современный стандарт)
**Формула обучения**:
```math
y_{train} = \frac{m \odot x}{1-p}
```

**Ключевое свойство**:
```math
𝔼[y_{train}] = x
```

**Инференс**:  
Просто используем выход как есть:
```math
y_{test} = x
```

## 📊 Сравнение методов

| Характеристика       | Standard Dropout | Inverted Dropout |
|----------------------|------------------|------------------|
| Масштабирование      | При инференсе    | При обучении     |
| Риск ошибки          | Высокий          | Нулевой          |
| Использование        | Устаревшее       | Современное      |

## 🔍 Почему важно сохранять матожидание?
1. **Стабильность распределения**  
   Предотвращает дрейф статистик активаций между слоями

2. **Согласованность обучения и инференса**  
   Обеспечивает одинаковое поведение модели на всех этапах

3. **Автоматизация**  
   Inverted Dropout исключает человеческий фактор

## 💻 Практическая реализация
```python
# PyTorch (использует Inverted Dropout)
dropout = nn.Dropout(p=0.5)  # Автоматически масштабирует на 1/(1-p)

# TensorFlow/Keras
dropout = tf.keras.layers.Dropout(rate=0.5)
```

## 📝 Выводы
1. Все современные фреймворки используют **Inverted Dropout**
2. Главная математическая суть — сохранение `𝔼[y] = x`
3. Метод особенно полезен в:
   - Больших сетях
   - Моделях со склонностью к переобучению
   - Задачах с ограниченными данными
